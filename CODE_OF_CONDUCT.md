# Code of conduct

Ferrodock follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the
work. Harassment or personal attacks aren't tolerated.

If something happens that makes you uncomfortable, contact the maintainer,
[@manimovassagh](https://github.com/manimovassagh), privately.
