# Getting help

- **Questions and ideas:** ask in
  [Discussions](https://github.com/manimovassagh/Ferrodock/discussions).
- **How do I…?** The [documentation](https://manimovassagh.github.io/Ferrodock/docs)
  covers installing, the engine, the CLI and the MCP server.
- **Something's broken:** open a
  [bug report](https://github.com/manimovassagh/Ferrodock/issues/new/choose)
  with your OS, Docker engine and Ferrodock version.
- **A security problem:** don't post it publicly; see [SECURITY.md](SECURITY.md).

Want to fix something yourself? See [CONTRIBUTING.md](CONTRIBUTING.md).
