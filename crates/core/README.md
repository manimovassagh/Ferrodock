# ferrodock-core

The Docker layer of [Ferrodock](https://github.com/manimovassagh/Ferrodock):
finding and connecting to Docker engines (including Ferrodock's own),
containers, images, volumes, networks, Compose projects, logs, stats and
Quick start templates. It has no UI code; the Ferrodock desktop app, the
`fdock` CLI and the MCP server are all built on it.
